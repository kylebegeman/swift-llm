# Scratch

This directory is for expendable working notes, experiments, raw prompt drafts, temporary evaluation captures, and research fragments.

Scratch files are not source of truth. They may be deleted, rewritten, or contradicted by durable docs without deprecation.

When a scratch idea becomes a real decision:

1. Move the durable conclusion into `docs/`.
2. Add or update any relevant `llm/` routing note.
3. Delete the stale scratch note or leave a short pointer to the durable doc.

Do not store private transcripts, API keys, user data, raw provider payloads, or sensitive Chime In recordings here.
