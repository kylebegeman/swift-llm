# Claude Routing

Follow the same routing rules as [`AGENTS.md`](AGENTS.md).

Start with [`llm/START_HERE.md`](llm/START_HERE.md), then read the narrow capability card or playbook for the task.

## Important Defaults

- `docs/` is durable documentation.
- `llm/` is compact agent guidance.
- `scratch/` is disposable incubation material.
- Xcode projects are generated by XcodeGen and should not be committed.
- Keep Chime In-specific workflows as examples or adapters until the abstraction is useful outside Chime In.
